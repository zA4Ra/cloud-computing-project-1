# Cloud Computing - Project 1

This project uses the **All_Diets.csv** dataset to demonstrate data analysis, Docker, cloud data processing, and CI/CD concepts.

## Project Tasks

### Task 1 & 2 – Data Analysis and Docker

- Analyzed the All_Diets.csv dataset using Python and Pandas.
- Created visualizations from the dataset.
- Dockerized the data analysis application.

### Task 3 – Cloud-Native Data Processing

- Set up Azurite to simulate Azure Blob Storage.
- Uploaded All_Diets.csv to Blob Storage.
- Created a Python serverless-style function to process the dataset.
- Calculated average protein, carbs, and fat for each diet type.
- Saved the processed results to results.json.

### Task 4 & 5 – CI/CD and Enhancements


- Created the CI/CD pipeline using GitHub Actions.
- Worked on the project enhancements.
