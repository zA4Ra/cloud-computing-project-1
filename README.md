# Cloud-Native Diet Analysis Dashboard

## Project Overview

This project is part of our Cloud Computing coursework and builds upon the work completed in Phase 1.

In Phase 1, we developed a Python-based data analysis solution using Azure Functions and Azurite Blob Storage to process the Diets Dataset.

In Phase 2, we will migrate our solution to Microsoft Azure and develop an interactive web dashboard to display nutritional data insights.

## Project Objectives

- Deploy an Azure Function to Microsoft Azure.
- Store and retrieve the Diets Dataset using Azure Blob Storage.
- Develop a web-based dashboard with at least three data visualizations.
- Connect the frontend dashboard to the Azure Function API.
- Implement interactive features such as filters and refresh buttons.
- Deploy the dashboard using Azure Static Web Apps or Azure App Service.

## Technologies

| Technology | Purpose |
